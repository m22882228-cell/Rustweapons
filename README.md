# Rust Weapons (Fabric, Minecraft 1.21.11)

Оружие из игры Rust в 3D-моделях из кубиков: АК-47, LR-300, MP5A4, Томпсон, M92, револьвер, Python, M39 EBR, L96 и SPAS-12.

## Управление (как в Rust)
- ЛКМ — выстрел (автоматы стреляют, пока держишь; остальное — по клику)
- ПКМ (держать) — прицеливание: приближение, меньше разброс и отдача
- R — перезарядка (клавишу можно поменять в настройках управления). При пустом магазине перезарядка идёт сама.
- Полоска на иконке оружия — сколько патронов в магазине
- Патроны берутся из инвентаря: 5.56 (винтовки), пистолетные, картечь. Бывают обычные, HV и зажигательные.
- Нужен мод GeckoLib 5.4.5 для Fabric 1.21.11

## Сборка
Пуш в GitHub, затем Actions -> build -> Artifacts. Готовый jar лежит в архиве `Artifacts` (берите файл без `-sources`).
Локально: `./gradlew build`, jar в `build/libs/`.
