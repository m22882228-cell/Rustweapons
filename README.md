# Rust Weapons (Fabric, Minecraft 1.21.11)

Оружие из игры Rust в 3D-моделях из кубиков: АК-47, LR-300, MP5A4, Томпсон, M92, револьвер, Python, M39 EBR, L96 и SPAS-12.

## Управление
- ПКМ (можно зажимать) — выстрел
- Shift + ПКМ — перезарядка (при пустом магазине перезарядка идёт сама при нажатии ПКМ)
- Полоска на иконке оружия — сколько патронов в магазине
- Патроны ищутся в инвентаре: 5.56 (винтовки), пистолетные (MP5, Томпсон, пистолеты), картечь (дробовик)
- Все предметы лежат во вкладке «Боевое» в творческом режиме, у всего есть крафт

## Сборка
Пуш в GitHub, затем Actions -> build -> Artifacts. Готовый jar лежит в архиве `Artifacts` (берите файл без `-sources`).
Локально: `./gradlew build`, jar в `build/libs/`.
